# Equestria at War: With Fire and Sword *(indev)*


## Comment tags in files
+ `(WFAS [PCWM] +)` – WFAS addition to an EAW file
(possible `[PCWM]` stands for *Prywhenian Civil War Module*&trade;)
+ `(WFAS [PCWM] ~)` – WFAS change to an EAW file
+ `(!)` – error
+ `(?)` – needs or may need a readjustment
+ `(>)` – to do
+ `(*)` – other note
+ `(RCW)` – “stolen from my RCW mod :)”
